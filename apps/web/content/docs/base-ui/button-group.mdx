## Installation

### CLI

```bash
npx shadcn@latest add https://crodic.dev/r/button-group.json
```

## Usage

```tsx
import { ButtonGroup } from "@/components/ui/button-group";
```

```tsx
<ButtonGroup>Click me</ButtonGroup>
```
