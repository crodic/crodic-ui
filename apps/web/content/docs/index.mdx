# Crodic UI

Welcome to **Crodic UI** — an open-source UI component library and registry built for Next.js (App Router), React 19, Tailwind CSS v4, and Radix UI Primitives.

## Features

- **Radix UI Primitives:** Headless, highly accessible UI components with full keyboard navigation and ARIA attributes.
- **shadcn CLI Compatible:** Install any component directly into your Next.js project using the official `shadcn` CLI.
- **50+ Pre-installed Base Components:** All standard components from `shadcn/ui` available out-of-the-box.
- **Custom Components:** Distinctive modern blocks including Bento Grids, Interactive Cards, and more.

## Quickstart

Install any component directly via the official `shadcn` CLI:

```bash
npx shadcn@latest add https://crodic.dev/r/button.json
```
